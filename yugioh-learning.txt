Je veux que tu développes un **site web mobile-first de gamification et d'apprentissage des combos Yu-Gi-Oh!**, destiné principalement à être utilisé sur smartphone.

Le projet sera hébergé statiquement via **GitLab Pages**, donc l'application doit fonctionner entièrement côté client et ne doit pas nécessiter de backend propriétaire.

Le premier deck implémenté sera **Memento / Mementotlan**, mais l'architecture doit être conçue dès le départ pour pouvoir ajouter facilement d'autres decks, combos et variantes d'exercices sans devoir réécrire le moteur.

---

# 1. OBJECTIF DU PROJET

Le but n'est PAS de faire un simulateur de Yu-Gi-Oh!.

Le but est de permettre au joueur de **mémoriser et automatiser les combos d'un deck** grâce à différents mini-jeux.

L'utilisateur choisit :

**Deck → Combo → Mode d'entraînement**

Puis le site lui fait travailler la ligne de combo sous différentes formes.

Le système doit progressivement transformer une combo longue et complexe en quelque chose que le joueur peut rappeler automatiquement.

Le projet doit donc privilégier :

* mémorisation
* rappel actif
* répétition
* compréhension de la logique du combo
* reconnaissance des cartes
* ordre des actions
* vocabulaire précis
* adaptation aux variantes

---

# 2. PRINCIPLE TRÈS IMPORTANT : LE JARGON DOIT ÊTRE STANDARDISÉ

Je veux utiliser un vocabulaire cohérent dans TOUTE l'application.

Ne change jamais arbitrairement les verbes utilisés pour une même action.

Par exemple, si une action est définie comme :

> "SS"

elle doit toujours pouvoir être affichée comme :

> Special Summon / SS

et pas parfois "invoquer spécialement", parfois "faire venir", parfois "summon", etc.

Même chose pour :

* NS = Normal Summon
* SS = Special Summon
* activate = Activer
* search = Chercher
* add = Ajouter à la main
* send = Envoyer au GY
* pop = Détruire
* shuffle = Mélanger dans le Deck
* banish = Bannir
* revive = Renvoyer / Invoquer depuis le GY selon le contexte
* summon = Invoquer
* fuse = Fusionner
* set = Poser
* float = Flotter / déclencher son effet de remplacement après destruction
* recover = Récupérer
* mill = Envoyer des cartes du Deck au GY

Le système de données doit permettre de définir précisément le verbe/action utilisé pour chaque étape.

**Ne reformule jamais les actions automatiquement.**

L'objectif est que le joueur mémorise exactement le langage utilisé pour le combo.

---

# 3. ARCHITECTURE DES DONNÉES

Ne hardcode pas les combos directement dans les composants React/HTML.

Créer une structure de données indépendante permettant de définir :

* decks
* cartes
* combos
* étapes
* branches
* variantes
* tags
* difficulté
* exercices

Par exemple, conceptuellement :

Deck
→ Combo
→ Phase/Section
→ Step
→ Branch

Une combo doit pouvoir avoir un squelette du type :

STARTER
↓
SETUP
↓
GY SETUP
↓
BOARD SETUP
↓
END BOARD

Et plusieurs branches à partir d'un point donné.

Exemple :

SETUP
├── Horned Dragon + Bone Party
├── Extending with Horned Dragon
└── Savage line

Le moteur d'exercices doit pouvoir utiliser cette structure.

# 4. PREMIER DECK : MEMENTO

Créer le deck :

**Memento**

Nom affiché :

**Memento / Mementotlan**

Le premier combo à intégrer est le combo suivant.

Nom :

**Angwitch 1-card combo**

Le combo doit être enregistré comme une suite d'étapes structurées et non comme un simple bloc de texte.

Voici la ligne de base :

1. NS Mementotlan Angwitch
2. Activate Mementotlan Angwitch to search Mementotlan Tatsunootoshigo
3. SS Mementotlan Tatsunootoshigo and activate it, popping itself, to send Mementotlan Mace, Mementotlan Goblin & Mementotlan Shleepy
4. Activate Mementotlan Angwitch, popping itself, to SS Mementotlan Mace
5. Activate Mementotlan Mace, popping itself, to search Mementotlan Fusion
6. Activate Mementotlan Fusion to SS Mementomictlan Tecuhtlica - Creation King by shuffling Mementotlan Tatsunootoshigo, Mementotlan Mace & Mementotlan Angwitch
7. Activate Mementomictlan Tecuhtlica - Creation King to send another Mementomictlan Tecuhtlica - Creation King, Mementotlan Akihiron & Mementotlan Ghattic
8. Mementotlan Ghattic effect to SS itself
9. Activate Mementotlan Ghattic to add Mementotlan Shleepy to hand
10. Mementomictlan Tecuhtlica - Creation King GY effect to search Mementomictlan
11. Activate Mementomictlan
12. CL1 Mementotlan Fusion in GY to pop Mementomictlan Tecuhtlica - Creation King and search Mementotlan Bone Party
13. CL2 Mementotlan Shleepy to SS itself from hand
14. New chain: CL1 Mementotlan Shleepy to SS Mementotlan Twin Dragon using Mementotlan Shleepy + Mementotlan Ghattic
15. CL2 Mementomictlan to SS Mementotlan Goblin
16. CL3 Mementotlan Akihiron to SS itself
17. Activate Mementotlan Twin Dragon, popping Mementotlan Akihiron, to add Mementotlan-Horned Dragon & Mementoal Tecuhtlica - Combined Creation
18. Activate Mementotlan Akihiron to add the banished Mementotlan Fusion to hand

Cette étape est extrêmement importante :

### SETUP COMPLETED

À partir de cette étape, la combo peut partir dans différentes directions.

Ne considère donc PAS la suite comme faisant partie d'une seule combo obligatoire.

# 5. BRANCHE : HORNED DRAGON + BONE PARTY

Créer une branche appelée :

**Horned Dragon + Bone Party**

Étapes :

1. Activate Mementotlan Goblin, popping Mementotlan Twin Dragon, to send 2 cards of choice
2. Mementotlan Twin Dragon GY effect to float into any body
3. Activate Mementotlan Bone Party to pop Mementoal Tecuhtlica - Combined Creation in hand to summon Mementotlan Dark Blade
4. Activate Mementotlan Dark Blade to SS Mementotlan Angwitch from Deck by popping anything
5. Link summon / build the desired Link line
6. SS Mementoal Tecuhtlica - Combined Creation by shuffling appropriate cards while keeping Mementotlan Akihiron and Mementotlan Dark Blade in GY
7. SS Mementotlan-Horned Dragon from hand
8. Set Mementotlan Fusion

Cette branche doit pouvoir être interrompue / personnalisée selon l'Extra Deck choisi.

---

# 6. BRANCHE : EXTENDING WITH HORNED DRAGON

Créer une autre branche :

**Extending with Horned Dragon**

Étapes :

1. SS Mementotlan-Horned Dragon from hand
2. Link summon Cross-Sheep using Mementotlan-Horned Dragon + Mementotlan Goblin
3. Activate Mementotlan Bone Party to pop Mementoal Tecuhtlica - Combined Creation in hand to summon Mementotlan Dark Blade in Cross-Sheep's zone
4. Activate Cross-Sheep to SS Mementotlan Goblin
5. Activate Mementotlan Dark Blade to SS Mementotlan Angwitch from Deck
6. Activate Mementotlan Goblin, popping Mementotlan Twin Dragon, to send 2 cards of choice
7. Build desired Link/Synchro board
8. During the End Phase, Field Spell sets Mementotlan Bone Party or another appropriate card

# 8. MODE DE JEU 1 — BASIC FORM

Créer un mode :

## "Basic Form"

Le joueur voit les cartes et les actions.

Exemple :

> 🧙 Mementotlan Angwitch
> ↓
> Search Mementotlan Tatsunootoshigo
> ↓
> 🐉 Mementotlan Tatsunootoshigo
> ↓
> Send Mace + Goblin + Shleepy
> ↓
> ...

Objectif :

**apprendre le squelette de la combo.**

Interface très lisible sur mobile.

Possibilité de :

* avancer étape par étape
* revenir en arrière
* afficher/masquer l'explication
* afficher les cartes
* afficher le nom exact de l'action

---

# 9. MODE DE JEU 2 — FILL IN THE BLANK

Mode :

## "Fill the Blank"

Le joueur voit une combo avec certaines informations masquées.

Exemple :

> NS Mementotlan Angwitch
> ↓
> Activate Angwitch to search ______
> ↓
> SS Mementotlan Tatsunootoshigo
> ↓
> Send Mementotlan Mace + ______ + Mementotlan Shleepy

Le joueur doit sélectionner ou écrire :

**Mementotlan Goblin**

Prévoir plusieurs niveaux :

### Easy

Nom de carte manquant.

### Medium

Action manquante.

### Hard

Carte + action manquantes.

### Expert

Plusieurs étapes consécutives manquantes.

---

# 10. MODE DE JEU 3 — PUT IN ORDER

Mode :

## "Put in Order"

Afficher plusieurs étapes mélangées.

Exemple :

* Activate Mementotlan Mace to search Mementotlan Fusion
* NS Mementotlan Angwitch
* Activate Mementotlan Fusion
* SS Mementotlan Tatsunootoshigo
* Activate Angwitch to search Tatsunootoshigo

Le joueur doit remettre les étapes dans le bon ordre.

Sur mobile :

**drag & drop** si fiable.

Sinon prévoir une interface tactile simple :

> sélectionner une étape → sélectionner sa position

Ne pas dépendre exclusivement du drag & drop.

# 12. IMAGES DES CARTES

Les images des cartes doivent être récupérées **dynamiquement**.

Ne pas stocker manuellement une copie de toutes les images dans le repository si cela peut être évité.

Utiliser une API/base de données publique de cartes Yu-Gi-Oh! adaptée pour récupérer :

* nom
* image
* éventuellement texte
* type
* attribut
* niveau

Prévoir un système de cache local pour éviter de refaire inutilement les mêmes requêtes.

Très important :

**ne jamais dépendre d'une URL d'image écrite manuellement pour chaque carte.**

Le système doit recevoir :

```text
"Mementotlan Angwitch"
```

et être capable de retrouver automatiquement son image.

Créer une couche/service du genre :

```text
CardRepository
CardImageService
```

afin de pouvoir changer de source plus tard sans modifier les mini-jeux.

Si l'API n'est pas disponible temporairement :

* afficher un placeholder propre
* ne pas casser l'application
* permettre au reste du jeu de fonctionner

# 23. IMPORTANT : PAS DE FAUSSE LOGIQUE YU-GI-OH!

Ne tente pas de recréer toutes les règles du jeu.

# 24. AFFICHAGE DU COMBO

Toujours afficher les combos comme une chaîne visuelle claire.

Exemple :

```text
🧙 Angwitch
      ↓
🔎 Search
      ↓
🐉 Tatsunootoshigo
      ↓
💥 Pop
      ↓
📤 Send
      ↓
🔨 Mace
      ↓
💥 Pop
      ↓
🌀 Fusion
```

Mais lorsque le joueur passe en mode avancé, afficher le texte exact de l'action.

Il doit donc exister deux niveaux :

### MEMORY VIEW

Très visuel :

> 🧙 → 🔎 → 🐉 → 💥 → 🔨 → 🌀

### TECHNICAL VIEW

Exact :

> NS Mementotlan Angwitch
> Activate Mementotlan Angwitch to search Mementotlan Tatsunootoshigo
> ...

Cela permettra d'utiliser à la fois la mémorisation par image/histoire et la mémorisation précise du combo.

# 28. AVANT DE CODER

Avant de commencer le développement, fais-moi d'abord un très court résumé de :

1. l'architecture proposée
2. la structure des données d'une combo
3. les composants principaux
4. comment tu vas récupérer les images
5. comment tu vas gérer GitLab Pages
6. comment les quatre mini-jeux vont utiliser les mêmes données

Puis commence directement l'implémentation.

Ne me demande pas de spécifier chaque détail visuel : prends des décisions raisonnables et garde l'interface simple.

Si un détail est ambigu, privilégie :

**simplicité → extensibilité → mobile → performance.**

Et surtout : **ne transforme pas les données de combo en texte libre difficile à exploiter.** Le même dataset doit pouvoir alimenter Basic Form, Fill the Blank, Put in Order et Story Mode.
